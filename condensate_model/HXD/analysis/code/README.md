### Code to analyze HXD of the Nup62 complex

- process_AA.py - code to analyze the radius of gyration of all atom simulations of an FG-Nup. These are compared to coarse grained simulations, detailed in Postmitotic_Nup62_OpenABC/condensate_model/Training
- slab simulations are analyzed with scripts in Postmitotic_Nup62_OpenABC/condensate_model/Slab_simulations/analysis/code
