### This directory contains the inputs for running simulations with a single Nup62-Nup58-Nup54 complex.
Final results include the results of 5 simulations with different random seeds.

To start simulations:
- python Nup62_Nup58_Nup54.py

To analyze simulations (where XXX is the name of the system):
- python ../analysis/code/Rg_monomer.py XXX.xml
